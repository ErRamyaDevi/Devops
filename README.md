# Devops
### Learning of Devops

What is DevOps? [Interview Question]
+ DevOps is a culture or practice. (Works based on some rules)
+ DevOps is a process of improving the application delivery by ensuring there is proper automation, code quality, continuous monitoring & continuous testing.[Every process should be automated]

Why DevOps?
Before 1 years, our application delivery was manual like Developers (code developing), System admin (creating servers) , BRE - Build and Release Engineers (deploys application on the server) ,  Server admin (makes server as application server) which includes 4 types of team to co-ordinate to deliver a single application.

It is a long Manual process which leads to consumption of time(days or weeks)

To Overcome these circumstances, DevOps came into picture.

# SDLC
### What is SDLC - Software Development Life Cycle?

Software development life cycle (SDLC) is a structured process that is used to design, develop, and test good-quality software.
or SDLC is a process that is followed by the industry to design, develop and testing to ensure the high quality product.

SDLC Lifecycle:
Planning & Requirements:
+ Defining
+ Designing - HLD & LLD
+ Building - Developing stage means Developers wrote the code share it with remote repositories like GitHub.  
+ Testing - Test the code in one server known as staging environment, then this quality will be ensured by Quality Engineers.
+ Deploy - Finlly, the code is pomoted to Production server to use or access by visitors or customers.
